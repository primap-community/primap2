Fixed a number of inconsistencies between the documentation and the actual behaviour.
Among others, `ds.pr.gas_basket_contents_sum` documented its `basket_units` parameter
under the wrong name, `da.pr.merge` documented a `combine_attrs` parameter which it does
not have, `ds.pr.add_aggregates_variables` and the `add_aggregates_coordinates` functions
documented wrong defaults for `min_count`, the downscaling functions did not mention that
`skipna=False` has to be given explicitly when using `skipna_evaluation_dims`, and the
`coverage` examples were missing the `pr` accessor.

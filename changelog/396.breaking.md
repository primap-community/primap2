* Processing information now stores only the last `primap2.ProcessingStepDescription` of
  each timeseries, which refers to earlier steps via `parents`, and step times are
  `primap2.TimeRange`s. `primap2.TimeseriesProcessingDescription` and `time="all"` were
  removed, and files saved with earlier versions can no longer be read.
* {py:meth}`xarray.Dataset.pr.ensure_valid` now checks the dimensions of processing
  information and that it exists for every timeseries with data.

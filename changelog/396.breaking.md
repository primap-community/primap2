Processing information now stores only the last `primap2.ProcessingStepDescription` of
each timeseries, which refers to earlier steps via its new `parents` attribute.
`primap2.TimeseriesProcessingDescription` was removed. The `time` of a processing step is
now given as `primap2.TimeRange`s, `"all"` is no longer supported. Files saved with
earlier versions can no longer be read.

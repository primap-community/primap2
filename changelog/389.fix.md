* Fixed writing datasets to netcdf where the processing information is missing for some
  timeseries, which happens for example if a dataset generated by the csg uses different
  categories for different variables. Missing processing information is now written as
  empty binary data and read back as `None` instead of raising an `AttributeError`.
* Removed the long-gone `history` attribute from the list of allowed `meta_data` keys in
  the docstrings of the `pm2io` reading functions and documented `publication_date`
  instead. Passing `history` produces an "Unknown metadata in attrs" warning from
  `ds.pr.ensure_valid()`.

* {py:meth}`xarray.Dataset.pr.convert_to_gwp`,
  {py:meth}`xarray.Dataset.pr.convert_to_gwp_like` and
  {py:meth}`xarray.Dataset.pr.convert_to_mass` now record the conversion in the processing
  information of the variables they convert.
* {py:meth}`xarray.Dataset.pr.fill_all_na` now works on datasets which carry processing
  information and records the filling in the processing information of the timeseries it
  fills.
* {py:meth}`xarray.Dataset.pr.fillna`, {py:meth}`xarray.Dataset.pr.combine_first`,
  {py:meth}`xarray.Dataset.pr.merge` and {py:meth}`xarray.Dataset.pr.set` now work on
  datasets which carry processing information and combine it with the processing
  information of the other dataset.
* {py:meth}`xarray.Dataset.pr.sum`, {py:meth}`xarray.Dataset.pr.add_aggregates_coordinates`,
  {py:meth}`xarray.Dataset.pr.add_aggregates_variables`,
  {py:meth}`xarray.Dataset.pr.downscale_timeseries`,
  {py:meth}`xarray.Dataset.pr.downscale_gas_timeseries` and
  {py:meth}`xarray.Dataset.pr.downscale_timeseries_by_shares` now work on datasets which
  carry processing information and record the timeseries the results were derived from
  as their parents.
* {py:meth}`xarray.Dataset.pr.ensure_valid` now checks that processing information has the
  same dimensions as the variable it describes, apart from the "time" dimension, which it
  must not have, and that a dataset with processing information has it for every
  timeseries with data.
* {py:func}`primap2.csg.compose` and {py:func}`primap2.csg.create_composite_source` now
  keep the processing information of the input data as parents of the composed
  timeseries. Skipped inputs and strategies are logged as debug messages instead of being
  recorded as processing steps.

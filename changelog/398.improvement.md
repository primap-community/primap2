The `skipna`, `skipna_evaluation_dims`, and `min_count` parameters now work the same in all functions which sum data. `ds.pr.add_aggregates_variables`, `ds.pr.add_aggregates_coordinates`, and `da.pr.add_aggregates_coordinates` gained the `skipna_evaluation_dims` parameter, and `da.pr.downscale_timeseries`, `ds.pr.downscale_timeseries`, and `ds.pr.downscale_gas_timeseries` gained the `min_count` parameter. The downscaling functions now accept `skipna_evaluation_dims` without also passing `skipna=False`. The default of `skipna` is now `None` everywhere, which does not change results for float data.

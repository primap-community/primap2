Processing information is now stored per data point: the `Processing of {var}` variables
have the dimensions of `{var}` including `time` and hold a `primap2.ProcessingStep` for
each data point with data, whose `parents` can be at any time point. The fields describing
a step are in the `primap2.ProcessingStepDescription` shared by the data points of a
timeseries which the step set. `primap2.ProcessingStepDescription` has the new fields
`variable` and `coords` and lost `time` (including `time="all"`), `unstructure` and
`structure`. `primap2.TimeseriesProcessingDescription` was removed. Files saved with
earlier versions can no longer be read.
Filling strategies of the composite source generator have to return
`primap2.csg.StrategyStep`s instead of `ProcessingStepDescription`s.
{py:meth}`xarray.Dataset.pr.to_interchange_format` now raises an error for datasets with
processing information instead of silently dropping it.

* Fixed `LocalTrendsStrategy` not filling a gap which consists of a single time point if the scaling factors on both sides differ.
* `LocalTrendsStrategy` now anchors the left and right scaling factors of a gap at the known years next to the gap instead of the first and last missing year, which changes the filled values if the factors differ.
* `LocalTrendsStrategy` now uses the fallback degree for both the timeseries and the fill timeseries (and both sides of a gap) if the default trend is not available for one of them, instead of comparing trends of different degrees.
